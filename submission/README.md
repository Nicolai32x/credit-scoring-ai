# Submission checklist

Upload to MS Teams by the presentation day. Folder name:
`YYYYMMDD_Topic`, using the actual date and agreed topic name.
The PDF does not specify a date. According to the Grading Regulations,
late submission costs 50% of the points.

- [ ] Report included as Markdown and PDF
- [ ] Shared Word draft reviewed by all authors; Markdown and PDF match the final content
- [ ] Business problem, existing solutions, and literature covered
- [ ] Generative AI experiment and your own review documented
- [ ] Empirical analysis includes goals, assumptions, results, and interpretation
- [ ] Presentation covers all required topics and includes author footers
- [ ] Presentation rehearsed to fit 20-25 minutes
- [ ] Practical demo rehearsed to fit 5-10 minutes
- [ ] Prompts and relevant AI outputs included
- [ ] Dataset included and redistribution rights checked
- [ ] UCI originals, dataset attribution, license link, and descriptions of data changes included
- [ ] Code, notebooks, and dependencies included
- [ ] Startup instructions and reproducibility checked on a second computer
- [ ] All team members can explain their contributions and the results
- [ ] No writing guidance, unfilled placeholders, or unsupported results remain in final deliverables
- [ ] No credentials, unnecessary personal data, or local environments included
- [ ] Upload verified to be complete and on time

Later, assemble the submission package in `submission/YYYYMMDD_Topic/`.
It is excluded from Git by default. This checklist remains versioned.
