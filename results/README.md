Generated by [notebook 01](../notebooks/01_exploration.ipynb) on 20 October 2026.
All observations below concern the **800 development cases**, not the 200
held-out test cases. Notebook 02 adds a fixed-configuration five-fold model
comparison. No final test results or saved final model exist yet.

## Main descriptive findings

- Labels: 560 good risks (70%) and 240 bad risks (30%). An always-good prediction
  gives 70% accuracy but no bad-risk recall. The cross-validated baseline below
  reproduces this reference calculation.
- No empty input values, repeated seven-feature profiles or unexpected category
  codes were found in development data. Combined unknown categories remain:
  savings code A65 accounts for 144 cases (18%).
- Credit amount: median 2,317 historical DM; mean 3,189.59 DM; range 276-15,945 DM.
  The upper tail is long. Large values are retained rather than assumed erroneous.
- Duration: median 18 months, mean 20.77 months, range 4-60 months.
- Small loan-purpose groups include retraining (5 cases), other (6), domestic
  appliances (10) and repairs (18). Their observed label shares are unstable.
- Numeric scales differ and categorical codes are identifiers. Notebook 02 now
  demonstrates encoding and numeric scaling learned inside one training fold,
  followed by model comparison with transformations refitted in each fold.

The notebook also shows category-level bad-risk shares with denominators and
small-group flags. These are descriptive associations, not causal effects,
validated individual probabilities, or decision rules. A group size of 20 is
only a display flag and does not establish statistical reliability.

## First model comparison: validation only

Notebook 02 fits each candidate on the same five stratified development folds,
seed 42. Each round has 640 training and 160 validation cases. Preprocessing is
fitted inside the training fold. There is no parameter or threshold search.
The two ML models use balanced class weights; the fixed score threshold is 0.5.
See the notebook and JSON for complete settings.

Values below are fold **mean +/- sample standard deviation**. Standard
deviations describe variation; they are not confidence intervals.

| Candidate | Accuracy | Balanced accuracy | Bad-risk recall | ROC-AUC | Illustrative cost/case |
| --- | --- | --- | --- | --- | --- |
| Majority baseline | 0.700 +/- 0.000 | 0.500 +/- 0.000 | 0.000 +/- 0.000 | 0.500 +/- 0.000 | 1.500 +/- 0.000 |
| Logistic regression | 0.708 +/- 0.041 | 0.709 +/- 0.048 | 0.713 +/- 0.094 | 0.766 +/- 0.050 | 0.638 +/- 0.138 |
| Random forest | 0.703 +/- 0.036 | 0.702 +/- 0.054 | 0.700 +/- 0.104 | 0.778 +/- 0.040 | 0.658 +/- 0.157 |

Pooled out-of-fold counts (800 predictions per candidate):

| Candidate | Bad risks detected / 240 | False approvals | False rejections | Total illustrative cost units |
| --- | --- | --- | --- | --- |
| Majority baseline | 0 | 240 | 0 | 1,200 |
| Logistic regression | 171 | 69 | 165 | 510 |
| Random forest | 168 | 72 | 166 | 526 |

Cost is `5 * false approvals + false rejections`, using the historical source's
illustrative assumption. Units are not currency or observed bank losses.

**Interpretation:** accuracy alone hides the baseline's failure to detect any
bad risks. Both ML models detect substantially more bad risks but falsely reject
many good risks. Only about half of the cases flagged bad are actually labeled
bad (pooled precision: logistic regression 0.509, forest 0.503). Logistic
regression leads slightly on the primary balanced-accuracy metric and this
cost assumption, while the forest has a slightly higher mean ROC-AUC. The
small differences do not establish a reliable winner. Logistic regression is
a reasonable provisional candidate because it is simpler and leads on the
chosen primary metric; this is not a frozen final selection.

The same folds compare candidates, which can make a selected score optimistic.
No calibrated future default probabilities, fairness conclusions, profitability
claims or contemporary lending suitability follow from this experiment. Review
the model/threshold decision before final testing; keep all 200 test cases reserved.
